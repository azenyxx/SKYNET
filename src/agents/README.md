# SKYNET AGT — Public Examples

Ten **independent, deliberately limited educational examples** aligned with AGT-001 through AGT-010. These are newly written examples, **not excerpts of the private AGT implementations**, and do not reproduce the original architecture or prove its correctness.

Python 3.10+; standard library only. Run `python -m unittest discover -s AGT -p "test_*.py"` (or use `python AGT/run_tests.py`). No network access, external services, persistent state or production execution.

Private research remains unqualified as a complete system; the source consolidation reported 263 PASS and 6 ERROR. These examples do not fix those errors.
