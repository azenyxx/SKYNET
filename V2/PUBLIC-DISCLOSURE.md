# Public Disclosure Policy — SKYNET v2.0

The public repository provides selected documentation and explicitly approved examples. It is not a mirror of the private development workspace.

**Not included:** private source code, model weights, unreleased algorithms, full architecture specifications, internal audit reports, credentials, key material, evaluation seeds, sealed test tasks, or sensitive infrastructure details.

Future releases are subject to explicit project-owner authorization and a separate disclosure review. A public update does not authorize publication of additional files.
