# Contributing to SKYNET

SKYNET welcomes constructive research and engineering contributions to its **public** materials.

## Where to start

- Open an Issue for a documentation correction, research proposal, or reproducible public experiment.
- Describe the problem, expected benefit, evidence, and limitations.
- For changes to executable public code released in the future, include reproducible tests and clearly distinguish fixture results from runtime evidence.
- Keep discussions respectful and focused on testable claims.

## Boundaries

Do not include private Cognitive Core code, unpublished research, credentials, personal data, internal infrastructure, or third-party material without redistribution rights. Do not assume access to private implementation or deployment systems. Do not use Issues for sensitive vulnerability reports.

By submitting a contribution, you must have the rights needed to provide it under the repository's MIT License. Maintainers may request revisions or decline contributions. Public contributions do not grant access to private research or governance authority.

This R1 repository is documentation-only; public implementation contributions will be scoped separately.
