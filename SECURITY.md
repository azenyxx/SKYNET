# Security Policy

SKYNET is an active research project. Do not deploy research code with unrestricted permissions or production credentials.

## Reporting

Report suspected vulnerabilities privately to the repository maintainers using GitHub's private vulnerability reporting feature when enabled, or contact the maintainers through the repository profile. Do not publish exploit details before coordinated disclosure.

## Scope

Public source and tests are provided for research and review. Default-deny authorization and controlled execution should remain enabled where supported.
