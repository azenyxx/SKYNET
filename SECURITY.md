# Security Policy

SKYNET R1 is a **documentation-only research preview**, not a deployed system or security-certified implementation.

## Reporting vulnerabilities

**Do not post vulnerabilities, credentials, private data, or exploit details in public GitHub Issues or Discussions.**

The project owner must enable and verify GitHub **Private Vulnerability Reporting** (Settings → Security → Code security and analysis / Private vulnerability reporting, where available), or publish an alternative validated private contact, **before inviting sensitive security reports**. Until confirmed, the private reporting channel is **PENDING**.

Please do not probe third-party infrastructure or systems without authorization.

## Current verification limits

PostgreSQL G3 verification is BLOCKED_ENVIRONMENT and NOT RUN. Real sandbox isolation, external provider behavior, and enforcement timing remain pending external verification. No mock or local test is presented as proof of production security.
