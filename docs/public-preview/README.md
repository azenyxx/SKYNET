# SKYNET — Public Architecture Preview

SKYNET is an experimental, offline-first reference architecture for deterministic task orchestration, structured memory, verification policies, and local fault observation.

**This repository is a documentation-only public preview.** It does not contain the private implementation, deployable runtime, or completed end-to-end system.

## Current scope

The internal SYS-001–SYS-006 modules have reported local qualifications, with documented limitations. SYS-005 has a process-budget exception. SYS-007 and SYS-008 are incomplete and are **not accepted** as full releases.

## Architecture

See [ARCHITECTURE.md](ARCHITECTURE.md) and [STATUS.md](STATUS.md).

## Security and claims

No claims of AGI, ASI, production readiness, durable recovery, distributed consensus, or independent truth verification. Do not use this preview for safety-critical operations.

## Source availability

Source code is not included in this preview. Publication of implementation and licensing require a separate review.
